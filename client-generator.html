🛠 ক্রেতার জন্য সফটওয়্যার কপি বানান

এই ফাইলটা শুধু আপনার কম্পিউটারে রাখুন, GitHub-এ আপলোড করবেন না। ফর্ম পূরণ করে "ZIP তৈরি করুন" চাপলে ক্রেতার নামে সাজানো একটা ZIP নামবে।

১. ক্রেতার তথ্য

লোগো না দিলে দোকানের নামের প্রথম অক্ষর দিয়ে একটা আইকন বানানো হবে।

২. ক্রেতার Firebase কনফিগ

ক্রেতার Firebase প্রজেক্ট থেকে firebaseConfig পুরোটা কপি করে এখানে বসান (নিচের গাইডের ৫ নম্বর ধাপ)।

৩. ক্রেতার Firestore Rules

ক্রেতার Firebase → Firestore Database → Rules-এ আগেরগুলো মুছে এটা বসিয়ে Publish করুন।




📋 প্রতিটা নতুন ক্রেতার জন্য ধাপগুলো


    

  1. লাইসেন্স যোগ: আপনার সফটওয়্যারে License Manager খুলে ক্রেতার দোকানের নাম, Gmail, মেয়াদ দিয়ে সেভ করুন। (এটা আগে না করলে ক্রেতার সফটওয়্যার লক হয়ে থাকবে।)
    2. 

  2. Firebase প্রজেক্ট: console.firebase.google.com → Add project → দোকানের নাম দিন → Google Analytics বন্ধ রাখুন → Create।
    3. 

  3. লগইন চালু: Build → Authentication → Get started → Email/Password চালু করুন → Users → Add user: ক্রেতার Gmail আর একটা পাসওয়ার্ড দিন।
    4. 

  4. ডেটাবেস: Build → Firestore Database → Create database → Production mode → কাছের লোকেশন (যেমন asia-south1) → Enable। তারপর Rules ট্যাবে উপরের ৩ নম্বর বক্সের নিয়ম বসিয়ে Publish।
    5. 

  5. কনফিগ: Project settings (গিয়ার আইকন) → Your apps → Web (</>) → একটা নাম দিয়ে Register → যে firebaseConfig দেখাবে তা কপি করে উপরে ২ নম্বর বক্সে বসান।
    6. 

  6. ZIP বানান: "ZIP তৈরি করুন" চাপুন। নামা ZIP-টা Extract করুন।
    7. 

  7. GitHub: (আমার পরামর্শ: আপনার নিজের GitHub অ্যাকাউন্টে, ক্রেতার নামে একটা নতুন Public repo বানান। এতে সাইট আপনার নিয়ন্ত্রণে থাকবে।) Add file → Upload files → Extract করা ফাইল ও icons ফোল্ডার টেনে ছাড়ুন → Commit।
    8. 

  8. সাইট চালু: repo → Settings → Pages → Branch: main, Folder: /(root) → Save। ১–২ মিনিটে https://আপনার-নাম.github.io/repo-নাম/ লিংক পাবেন।
    9. 

  9. ডোমেইন অনুমতি: ক্রেতার Firebase → Authentication → Settings → Authorized domains → Add domain: আপনার-নাম.github.io (শুধু এটুকু, /repo-নাম ছাড়া)।
    10. 

  10. পরীক্ষা: লিংক খুলে ক্রেতার Gmail আর পাসওয়ার্ডে লগইন করে দেখুন। তারপর ক্রেতাকে লিংক আর লগইন তথ্য দিন, পাসওয়ার্ড বদলে নিতে বলুন (লগইন পাতায় "পাসওয়ার্ড ভুলে গেছি" আছে)।
    11. 



⚠ আপনার নিজের সফটওয়্যারে নতুন ফিচার দিলে প্রতিটা ক্রেতার repo-তে নতুন index.html আপলোড করতে হবে। তবে এই জেনারেটর দিয়ে আবার ZIP বানিয়ে শুধু index.html বদলালেই চলবে।
